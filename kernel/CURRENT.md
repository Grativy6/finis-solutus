## Authority boundary

v0.16 remains a draft. This repository does not silently convert it into a stable release.

An active campaign remains bound to the kernel named in its rules lock until an explicit migration occurs at a resolved boundary. A new project draft does not rewrite existing campaign state, replay events, refill resources, duplicate rewards, or erase open obligations.

The DOCX is the authored source artifact. The Markdown file is a mechanical convenience rendering. If they materially differ because of conversion, the DOCX controls until the rendering is corrected.

Earlier files in [`../history`](../history/) are preserved ancestry. They do not override v0.16 and should not be treated as independent support for claims originating in the same development lineage.
