# Finis Solutus Development Track

This directory preserves the supplied development artifacts **byte-for-byte**. They record how Finis Solutus grew; they are not simultaneous rulebooks.

The current project kernel is [v0.16 Draft](../kernel/CURRENT.md). Earlier versions are development ancestry and provenance only. They do not override the active kernel, silently migrate a campaign, or independently corroborate one another.

`v0.2` was not supplied and is recorded as an archival gap. No contents, date, or replacement have been inferred.
