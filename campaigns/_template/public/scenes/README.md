# Scenes

Store each scene as an immutable numbered record, for example:

- `0001-opening.md`
- `0001-cut.md`
- `0001-resolution.md`

An opening declares the state revision, governing references, DM account, UTC open/cut times, active characters, Setting, public situation, and public Status projections.

A cut records admitted, superseded, late, withdrawn, and rejected turn sources. A resolution links the receipt that changes campaign state.
