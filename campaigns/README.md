# Campaigns

This directory is reserved for **public campaign traces**.

Use [`_template/`](_template/) to start a campaign. Copy it to a stable campaign ID, fill the rules lock before play, and preserve every accepted revision rather than overwriting history silently.

A public branch does not need certification to be playable or legitimate. If Branchline certification becomes operational, its status and immutable record belong in the campaign manifest and rules lock; compatibility, popularity, or a copied badge is not certification.

Public campaign material may include:

- the campaign description and declared modes;
- public character cards;
- scene openings and admitted turn snapshots;
- numbered DM resolutions;
- public state and receipts;
- corrections, migrations, and open items.

Never commit exact NPC mechanics, unrevealed facts, DM plans, private character material, credentials, or identifying human data unnecessary for play. Keep all private DM state in a separate private repository or local store—not merely an ignored folder inside a public clone.
